# References

The design follows the programmers model, interfaces and behaviour of the

**Arm CoreLink DMA-350 Controller Technical Reference Manual** (TRM).

The manual is copyrighted by Arm Limited and is **not** redistributed in this repository. It is available from Arm:
search for "DMA-350 Technical Reference Manual" at <https://developer.arm.com/documentation>.

The documentation in `docs/` cites the manual by section number (for example "TRM 4.3.6" or "TRM Fig. 5-17"); keep the
PDF next to you when you read the [waveform guide](../docs/waveform/README.md) or the
[consistency report](../docs/waveform/11_consistency_report.md). You can save a local copy in this folder; PDF files
here are ignored by git (see `.gitignore`).

Other specifications mentioned in the documents: AMBA APB, AMBA AXI, AMBA AXI-Stream and AMBA Low Power Interface, all
available from Arm.
