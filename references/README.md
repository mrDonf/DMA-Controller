# References

The design follows the programmers model, interfaces and behaviour of

**Arm® CoreLink™ DMA-350 Controller Technical Reference Manual**, document ID **102482_0000_04** (Issue 04).

The manual is copyrighted by Arm Limited and is **not** redistributed in this repository. It is available from Arm:
search for "DMA-350 Technical Reference Manual 102482" at <https://developer.arm.com/documentation>.

The documentation in `docs/` cites the manual by section number (for example "TRM 4.3.6" or "TRM Fig. 5-17"); keep the
PDF next to you when you read the [waveform guide](../docs/waveform/README.md) or the
[consistency report](../docs/waveform/11_consistency_report.md). To keep a local copy in this folder, save it as
`references/arm_corelink_dma-350_controller_technical_reference_manual_102482_0000_04_en.pdf` (this file name is ignored
by git, see `.gitignore`).

Other specifications mentioned in the documents: AMBA APB (IHI 0024), AMBA AXI and ACE (IHI 0022), AMBA AXI-Stream
(IHI 0051) and AMBA Low Power Interface (IHI 0068), all available from Arm.
